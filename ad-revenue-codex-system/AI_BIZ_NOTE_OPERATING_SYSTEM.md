# AI Biz Note Operating System

AI Biz Noteは、AIエージェントを事業成長メディア企業のように分担させて運営する。
最終目標は、広告収益・アフィリエイト・相談導線・テンプレート販売・受託支援を組み合わせて、月100万円以上の収益基盤を作ること。

## 目標

- Phase 1: AdSense審査通過
- Phase 2: 60記事、全記事2000〜3000字、内部リンク整理
- Phase 3: Search Consoleで表示回数が出た記事を毎週リライト
- Phase 4: 月1万PV
- Phase 5: 月3万PV
- Phase 6: 月10万PV
- Phase 7: 複数収益導線で月100万円の土台を構築
- Phase 8: 商品、相談、受託支援、SNS拡散を拡張して月100万円を安定化する

広告だけで月100万円を狙う場合、RPM800円なら約125万PVが必要。
そのためAI Biz Noteでは、広告だけに依存せず、アフィリエイト、相談、テンプレート販売、note販売、実装支援、業務改善支援を組み合わせる。

## AI組織図

### 1. 編集長エージェント

責任:
- サイト全体の方針を決める
- 記事テーマの優先順位を決める
- 読者像と収益導線がずれていないか確認する

見る指標:
- 記事数
- カテゴリの偏り
- 読者の悩みの深さ
- 収益導線との距離

判断基準:
- 事業者・個人・チームが実装に移せる内容か
- AI・検索・広告・SNS・商品化・業務自動化・収益導線のどれかに入るか
- 広告収益だけでなく、相談や商品導線にもつながるか
- 月100万円に向けて、PVだけでなく商品販売、相談、受託支援へつながるか

### 2. SEOリサーチャーエージェント

責任:
- 検索されるテーマを探す
- Search Consoleの表示回数・検索語句を見る
- 競合記事との差分を見つける
- 毎日、AI・検索・広告・SNSのトレンドから記事化候補を探す

見る指標:
- 表示回数
- クリック数
- CTR
- 平均掲載順位
- 検索語句

成果物:
- 次に書く記事テーマ
- リライト候補
- 内部リンク候補
- タイトル改善案
- 今日のトレンド記事候補
- Xで拡散する切り口

### 3. ライターエージェント

責任:
- 2000〜3000字の記事を書く
- 具体例、手順、失敗例、チェックリストを入れる
- 読者が次に行動できる文章にする

記事の基本構成:
- 導入
- 読者の悩み
- 具体的な手順
- よくある失敗
- 確認チェックリスト
- 小さく始める方法
- まとめ

禁止:
- 抽象論だけで終わる
- AIっぽい一般論だけにする
- 根拠のない断定をする
- 収益だけをあおる

### 4. 編集・品質管理エージェント

責任:
- 記事の読みやすさを確認する
- 日付、カテゴリ、内部リンク、説明文を確認する
- AdSense審査に不利な薄い内容を減らす

チェック項目:
- 2000字以上あるか
- 具体例があるか
- 読者の不安に答えているか
- タイトルと本文が一致しているか
- 投稿日・更新日が入っているか
- 誇張表現がないか

### 5. 収益化エージェント

責任:
- AdSense、アフィリエイト、相談導線、テンプレート販売の設計をする
- 記事ごとに主な収益導線を決める
- 月100万円に向けた収益ポートフォリオを管理する

導線タイプ:
- AdSense向き: 用語解説、基礎知識、チェックリスト
- アフィリエイト向き: AIツール比較、SEOツール、ノーコードツール
- 相談向き: LP改善、業務自動化、問い合わせ導線
- 商品向き: テンプレート、チェックリスト、プロンプト集
- 受託支援向き: AI実装、サイト改善、SNS導線設計、業務自動化の実装代行

### 6. 技術・公開エージェント

責任:
- `articles.json` を壊さず更新する
- `build-site.mjs` でサイト生成する
- `public/` の生成結果を確認する
- GitHub/Netlify公開導線を維持する
- `ads.txt`、`sitemap.xml`、`robots.txt` を確認する

公開前チェック:
- 記事数
- 生成HTML数
- sitemapの記事URL数
- AdSenseコード
- ads.txt
- 日付表示

### 7. 分析・月次レビューエージェント

責任:
- 月次で成果を見て次の打ち手を決める
- 伸びた記事、伸びない記事、収益導線を確認する

月次で見る数字:
- 月間PV
- AdSense収益
- RPM
- Search Console表示回数
- Search Consoleクリック数
- 上位記事
- 問い合わせ数
- アフィリエイトクリック数

### 8. 実行管理エージェント

責任:
- 日曜レポートや分析結果を、翌週の実作業に分解する
- 優先順位、担当、公開要否を決める
- 未完了タスクを次回へ持ち越す
- note販売、SNS投稿、Search Console確認、記事改善を実行リストにする

見るもの:
- 日曜運営レポート
- SNS下書き
- note販売文
- Search Consoleの数値
- AdSense審査状況
- 相談メニューの問い合わせ状況

成果物:
- 今週の実行リスト
- ユーザーがやること
- Codexがやること
- 公開が必要なもの、不要なもの
- 持ち越しタスク

判断基準:
- 収益導線に近い作業を優先する
- 公開前に人の確認が必要な作業を明確にする
- 記事追加だけに偏らず、販売・拡散・計測を回す

### 9. ニュース分析・本質解説エージェント

責任:
- AI、検索、広告、SNS、プラットフォーム変更などのニュースを確認する
- ニュースの要約だけでなく、事業者・個人・チームやAI Biz Note運営への影響を解説する
- 短期的な話題性と、長期的に残る本質を分ける
- 読者が次に何を確認すべきか、何を急がなくてよいかを整理する
- 毎日、記事化すべきニュースを1件以上選定する

見るもの:
- 公式発表
- 一次情報
- 信頼できる調査レポート
- 検索や広告、SNS運用への影響
- AI Biz Noteの既存記事や相談導線との接点

成果物:
- ニュース解説記事
- 影響度メモ
- 既存記事への追記候補
- noteやXで使う短い解説
- X投稿案
- note展開案
- 相談メニューへの接続案

記事の基本構成:
- 何が起きたか
- 何が変わる可能性があるか
- 事業者・個人・チームに関係あること
- すぐやること
- まだ急がなくてよいこと
- AI Biz Noteとしての見解

禁止:
- 見出しだけで煽る
- 未確認情報を断定する
- 公式情報と推測を混ぜる
- ニュースの翻訳だけで終わる

## 週次運営リズム

### 毎日: トレンド確認と拡散

- AI、検索、広告、SNS、noteの重要ニュースを確認する
- 今日記事化すべきニュースを1件選ぶ
- 記事化しないニュースはX投稿または保留に分ける
- 公開済み記事をXで1本以上拡散する
- 相談、note販売、実装支援につながる導線を確認する

### 月曜: 司令会議

- 今週の優先テーマを決める
- 新規記事かリライトかを決める
- 収益導線を確認する

### 火曜〜水曜: 制作

- 新規記事を2〜5本作る
- 既存記事を1〜3本リライトする
- 内部リンクを追加する

### 木曜: 品質管理

- 文字数
- 具体性
- 日付
- タイトル
- 収益導線
- AdSense審査上の安全性

### 金曜: 公開

- サイト生成
- 公開用フォルダへコピー
- GitHub/Netlifyへ反映
- 公開URL確認

### 日曜: 分析と実行計画

- 直近の作業状況を整理する
- AIトレンドと検索・広告の変化を確認する
- 重要ニュースを本質解説記事にするべきか判断する
- 翌週の優先順位を決める
- 実行管理エージェントが、レポートを具体的な作業リストに変換する

### 月末: レビュー

- 伸びている記事を確認
- 伸びない記事を改善
- 次月の記事テーマを決める
- 月100万円までの差分を確認
