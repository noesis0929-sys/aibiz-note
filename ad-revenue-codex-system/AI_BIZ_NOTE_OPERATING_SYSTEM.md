# AI Biz Note Operating System

AI Biz Noteは、AIエージェントを小さなメディア企業のように分担させて運営する。
最終目標は、広告収益・アフィリエイト・相談導線・テンプレート販売を組み合わせて、月20万円以上の収益基盤を作ること。

## 目標

- Phase 1: AdSense審査通過
- Phase 2: 60記事、全記事2000〜3000字、内部リンク整理
- Phase 3: Search Consoleで表示回数が出た記事を毎週リライト
- Phase 4: 月1万PV
- Phase 5: 月3万PV
- Phase 6: 月10万PV
- Phase 7: 月20万円の収益導線を構築

広告だけで月20万円を狙う場合、RPM800円なら約25万PVが必要。
ただしAI Biz Noteでは、広告だけに依存せず、アフィリエイト、相談、テンプレート販売も組み合わせる。

## AI組織図

### 1. 編集長エージェント

責任:
- サイト全体の方針を決める
- 記事テーマの優先順位を決める
- 読者像と収益導線がずれていないか確認する

見る指標:
- 記事数
- カテゴリの偏り
- 読者の悩みの深さ
- 収益導線との距離

判断基準:
- 小さな事業者が明日使える内容か
- AI活用、Web集客、LP改善、広告収益、業務自動化のどれかに入るか
- 広告収益だけでなく、相談や商品導線にもつながるか

### 2. SEOリサーチャーエージェント

責任:
- 検索されるテーマを探す
- Search Consoleの表示回数・検索語句を見る
- 競合記事との差分を見つける

見る指標:
- 表示回数
- クリック数
- CTR
- 平均掲載順位
- 検索語句

成果物:
- 次に書く記事テーマ
- リライト候補
- 内部リンク候補
- タイトル改善案

### 3. ライターエージェント

責任:
- 2000〜3000字の記事を書く
- 具体例、手順、失敗例、チェックリストを入れる
- 読者が次に行動できる文章にする

記事の基本構成:
- 導入
- 読者の悩み
- 具体的な手順
- よくある失敗
- 確認チェックリスト
- 小さく始める方法
- まとめ

禁止:
- 抽象論だけで終わる
- AIっぽい一般論だけにする
- 根拠のない断定をする
- 収益だけをあおる

### 4. 編集・品質管理エージェント

責任:
- 記事の読みやすさを確認する
- 日付、カテゴリ、内部リンク、説明文を確認する
- AdSense審査に不利な薄い内容を減らす

チェック項目:
- 2000字以上あるか
- 具体例があるか
- 読者の不安に答えているか
- タイトルと本文が一致しているか
- 投稿日・更新日が入っているか
- 誇張表現がないか

### 5. 収益化エージェント

責任:
- AdSense、アフィリエイト、相談導線、テンプレート販売の設計をする
- 記事ごとに主な収益導線を決める

導線タイプ:
- AdSense向き: 用語解説、基礎知識、チェックリスト
- アフィリエイト向き: AIツール比較、SEOツール、ノーコードツール
- 相談向き: LP改善、業務自動化、問い合わせ導線
- 商品向き: テンプレート、チェックリスト、プロンプト集

### 6. 技術・公開エージェント

責任:
- `articles.json` を壊さず更新する
- `build-site.mjs` でサイト生成する
- `public/` の生成結果を確認する
- GitHub/Netlify公開導線を維持する
- `ads.txt`、`sitemap.xml`、`robots.txt` を確認する

公開前チェック:
- 記事数
- 生成HTML数
- sitemapの記事URL数
- AdSenseコード
- ads.txt
- 日付表示

### 7. 分析・月次レビューエージェント

責任:
- 月次で成果を見て次の打ち手を決める
- 伸びた記事、伸びない記事、収益導線を確認する

月次で見る数字:
- 月間PV
- AdSense収益
- RPM
- Search Console表示回数
- Search Consoleクリック数
- 上位記事
- 問い合わせ数
- アフィリエイトクリック数

## 週次運営リズム

### 月曜: 司令会議

- 今週の優先テーマを決める
- 新規記事かリライトかを決める
- 収益導線を確認する

### 火曜〜水曜: 制作

- 新規記事を2〜5本作る
- 既存記事を1〜3本リライトする
- 内部リンクを追加する

### 木曜: 品質管理

- 文字数
- 具体性
- 日付
- タイトル
- 収益導線
- AdSense審査上の安全性

### 金曜: 公開

- サイト生成
- 公開用フォルダへコピー
- GitHub/Netlifyへ反映
- 公開URL確認

### 月末: レビュー

- 伸びている記事を確認
- 伸びない記事を改善
- 次月の記事テーマを決める
- 月20万円までの差分を確認
